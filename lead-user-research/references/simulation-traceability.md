# Simulation research-to-implementation traceability

[Source versions and review coverage](simulation-source-coverage.md). The unit of this inventory is a distinct procedure, measurable check, or source-specific design choice. A workflow integration is a bounded procedure in the skill. A companion integration identifies the executable owner. A proposed adaptation still needs empirical testing. An open row records missing source, implementation, or verification work. The [source findings](simulation-source-audit.md) preserve the paper and code locators for the follow-up audit. None of these dispositions upgrades a model output to human evidence.

## Independent review

A second reviewer inspected changes across the three repositories against the
retrieved primary sources. The independent arithmetic check matched AUROC to
direct pair counting on 2,000 deterministic tied and untied fixtures and
matched ordered Wasserstein to an unequal-spacing fixture. Evidence gates and
workflow findings were reviewed separately. This is engineering and methodology
review of the draft, with empirical validation still open.

| Finding | Disposition |
|---|---|
| A model estimate could be registered with a conflicting real basis. | Reject known estimate labels in both live registries. Tests cover conflicting real bases, and the state contract describes the diagnostic. |
| The standalone prompt omitted registry and freeze safeguards. | Restored separation, one mode per run, post-freeze handling and grade limits. |
| The canonical Decision Brief needed a persisted route for simulation context. | G records it as provisional uncertainty and supplies the pending real test in fields the renderer supports. H checks the rendered result. |
| Source procedure details differed from shorthand adaptations. | Clarified whole-community Multiverse, Smallville's recency implementation, SocSci210 normalization, variance/DSL scope and noise correction. |
| SSR regularization and validation needed explicit limits. | Recorded legacy behavior, single-minimum math, all-identical quality refusal, per-anchor output limits and measurement-choice attestation. |
| Source and verification coverage was ambiguous in several rows. | Distinguished the Socrates project README from code, inspected selected OSF analysis files, and separated tests from open empirical work. |
