Planning Skills for Agents and Humans

Privacy Policy

Effective October 6, 2026

This policy describes how the Planning Skills for Agents and Humans plugin (“Planning Skills”) handles information when you use its hosted MCP tools and project website.

Information processed

Planning Skills may receive the tool inputs needed to answer a request, such as planning context, a requested skill name, a requested artifact name, or a bounded resource path. The current MCP service does not require a Planning Skills account, OAuth login, payment information, or advertising profile.

How information is used

Information sent to the MCP service is used only to perform the requested planning operation, such as recommending a planning workflow or returning a canonical skill, template, contract, manifest, or support resource.

Storage and logging

The Planning Skills application does not intentionally persist user tool inputs or returned planning content as application data. The hosting provider may process ordinary infrastructure data, such as IP address, timestamps, request metadata, and service logs, to operate and secure the service. Application logging is limited to infrastructure and transport failures and is not designed to record user tool arguments or returned planning content.

Third-party services

The hosted MCP service runs on Railway. The project website is published with GitHub Pages. Your use of ChatGPT, Codex, or another host is also subject to that host’s own privacy terms. These providers may process information independently when delivering their services.

Sharing and sale

Planning Skills does not sell personal information and does not use user data for advertising. Information may be processed by infrastructure providers only as needed to operate, secure, and deliver the service, or disclosed when required by law.

Security

The public MCP service uses HTTPS. Its current tools are read-only and do not mutate external user data. No internet-facing service can be guaranteed perfectly secure.

Your choices

You control what planning context you send to the plugin. Avoid including secrets or sensitive personal information that is not needed for the planning task. Because the application does not intentionally retain user tool inputs as application records, it generally has no user-content account record to retrieve or delete.

Changes

This policy may change as the plugin gains capabilities. Material changes will be reflected on this page and in the effective date above.

Contact

For privacy questions or requests, open an issue in the Planning Skills support repository.
