Planning Skills

Privacy Policy

Effective date: October 6, 2026

What the Plugin does

Planning Skills provides product-planning workflows and read-only MCP tools for routing, canonical skill resources, templates, artifact contracts, and orchestration rules. The current MCP tools do not modify external systems and do not require a user account, OAuth connection, or API key.

Information processed

The Plugin processes only the information needed to respond to a tool call. Depending on the request, this can include task-specific text or planning context sent as MCP tool arguments; explicit skill names, resource paths, artifact names, or exclusions; and standard network and operational metadata processed by hosting providers.

The Plugin is not designed to collect payment-card data, protected health information, government identifiers, passwords, API keys, MFA codes, or other authentication secrets. Do not send those categories of information to the Plugin.

How information is used

Information is processed only to return the requested planning guidance or canonical resource, operate and secure the MCP service, troubleshoot failures, and respond to support requests.

Planning Skills does not sell personal data, serve advertising, or use Plugin activity for behavioral profiling.

Sharing and service providers

Information may be processed by services needed to provide the Plugin: OpenAI when you invoke it from a supported OpenAI surface; Railway, which hosts the public MCP server; and GitHub / GitHub Pages, which hosts the source repository, documentation, policy pages, and public support issue tracker. Those providers process information under their own terms and privacy policies.

Retention

The Planning Skills MCP application does not intentionally persist tool inputs or tool outputs in an application database after a request completes, and the application code does not intentionally log the content of successful tool calls.

Operational or security logs maintained by hosting and platform providers may be retained according to those providers' configurations and policies. Support requests submitted through GitHub are retained in the repository's issue history unless removed or edited.

Your choices and controls

  • Choose what task-specific information you send to the Plugin.
  • Stop using or disconnect the Plugin at any time through the host product.
  • Avoid including sensitive or restricted data.
  • Request support through the project's public issue tracker. Do not place sensitive personal information in a public issue.

Children

The Plugin is not directed to children under 13.

Changes

This policy may be updated as the Plugin changes. Material changes will be published in the repository and on this page with a new effective date.

Contact

For support or privacy questions, use the project issue tracker without posting sensitive information.
