# Privacy Policy

**Effective date: October 6, 2026**

This Privacy Policy describes how **Planning Skills** (the "Plugin"), published by Matt Lane, handles information when you use the Planning Skills plugin, its hosted Model Context Protocol (MCP) server, or the associated project website.

## What the Plugin does

Planning Skills provides product-planning workflows and read-only MCP tools for routing, canonical skill resources, templates, artifact contracts, and orchestration rules. The current MCP tools do not modify external systems and do not require an account, OAuth connection, or API key from the user.

## Information processed

The Plugin processes only the information needed to respond to a tool call. Depending on what you ask ChatGPT or Codex to do, this can include:

- the task-specific text or planning context that the client sends as MCP tool arguments;
- explicit skill names, resource paths, artifact names, or exclusions included in a tool call; and
- standard network and operational metadata that hosting providers may process to deliver and secure the service.

The Plugin is not designed to collect payment-card data, protected health information, government identifiers, passwords, API keys, MFA codes, or other authentication secrets. Do not send those categories of information to the Plugin.

## How information is used

Information is processed only to:

- return the requested planning guidance, canonical resource, template, contract, or routing result;
- operate, secure, and troubleshoot the MCP service; and
- respond to support requests.

Planning Skills does not sell personal data, serve advertising, or use Plugin activity for behavioral profiling.

## Sharing and service providers

Information may be processed by the services needed to provide the Plugin:

- **OpenAI**, when you invoke the Plugin from ChatGPT, Codex, or another supported OpenAI surface;
- **Railway**, which hosts the public MCP server; and
- **GitHub / GitHub Pages**, which hosts the source repository, documentation, policy pages, and public support issue tracker.

Those providers process information under their own terms and privacy policies.

## Retention

The Planning Skills MCP application does not intentionally persist tool inputs or tool outputs in an application database after a request completes. The application code does not intentionally log the content of successful tool calls.

Operational or security logs maintained by hosting and platform providers may be retained according to those providers' configurations and policies. Support requests submitted through GitHub are retained in the repository's issue history unless removed or edited.

## Your choices and controls

You can:

- choose what task-specific information you send to the Plugin;
- stop using or disconnect the Plugin at any time through the host product;
- avoid including sensitive or restricted data; and
- request support through the project's public issue tracker. Do not place sensitive personal information in a public issue.

## Children

The Plugin is not directed to children under 13.

## Changes

This policy may be updated as the Plugin changes. Material changes will be published in this repository and on this page with a new effective date.
